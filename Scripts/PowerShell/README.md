
# PowerShell Scripts

This directory contains PowerShell scripts developed to demonstrate automation, system administration, and IT operations tasks.

Scripts in this portfolio are based on lab environments, personal projects, and sanitized recreations of solutions developed through professional experience.

## Areas Covered

- Microsoft 365 administration
- Active Directory administration
- User and group management
- System configuration
- IT task automation
- Reporting and auditing

## Disclaimer

All scripts and examples in this repository have been created or recreated for portfolio purposes. Any names, domains, users, organizations, IP addresses, credentials, or other identifying information are fictional or redacted. No proprietary or confidential information is included.
