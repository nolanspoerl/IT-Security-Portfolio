
# Automated Employee Onboarding & Offboarding

This project focused on designing and automating a standardized **employee onboarding and offboarding process** using Microsoft Entra ID and Power Automate.

## Project Overview

Collaborated with HR, IT, and other departments to identify access requirements and establish standardized processes for employee lifecycle management.

Automation was implemented to reduce manual administrative work, improve consistency, and ensure employees received the appropriate access based on their role and department.

## Technologies & Tools

- Microsoft Entra ID
- Microsoft Power Automate
- Microsoft 365
- Microsoft Forms
- SharePoint / OneDrive
- Graph API
- PowerShell

## Key Accomplishments

- Automated portions of the employee onboarding and offboarding lifecycle
- Standardized user access based on department and job role
- Aligned IT provisioning processes with HR workflows
- Coordinated requirements across multiple departments
- Reduced repetitive manual administrative tasks
- Improved consistency of account provisioning and access removal
- Established documented onboarding and offboarding procedures

## Security & Privacy

This project has been recreated and sanitized for portfolio purposes. No employee information, credentials, internal company data, or proprietary configurations are included.
