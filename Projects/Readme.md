# IT Projects

This directory contains technical projects demonstrating hands-on experience with systems administration, cloud services, endpoint management, infrastructure, automation, and IT operations.

Projects include both lab-based implementations and sanitized recreations of solutions developed through professional experience.

## Featured Projects

Projects in this directory may include:

- Microsoft 365 administration and migrations
- Microsoft Intune / MDM deployments
- Active Directory and identity management
- Windows Server administration
- Endpoint configuration and management
- Network infrastructure
- Cloud services and deployments
- IT automation
- Security implementations
- Technical documentation and process improvement

## Project Documentation

Each project includes documentation covering relevant areas such as:

- Project overview and objectives
- Technologies and tools used
- Implementation process
- Configuration and deployment
- Troubleshooting and challenges
- Results and lessons learned

## Security & Privacy

All projects have been created or recreated for portfolio purposes. Sensitive name, domains, users, devices, credentials, IP addresses, tenant information, and other sensitive information have been removed or replaced with fictional examples or placeholders.
