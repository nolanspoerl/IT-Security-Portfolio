
# Microsoft 365 MFA & Conditional Access Rollout

Led an organization-wide rollout of **Multi-Factor Authentication (MFA)** and Microsoft Entra Conditional Access to strengthen identity security and standardize authentication across Microsoft 365.

## Project Overview

Planned and implemented the transition to MFA across the organization, including Conditional Access policy configuration, authentication method standardization, user enrollment, end-user communication, and post-deployment support.

## Technologies & Tools

- Microsoft Entra ID
- Microsoft 365
- Microsoft Authenticator
- Conditional Access
- Named Locations
- Authentication Methods / Security Info

## Key Responsibilities

- Planned and led the organization-wide MFA rollout
- Created and configured **Conditional Access policies** to enforce MFA requirements
- Configured **Named Locations** to support location-aware access policies
- Defined policy assignments, exclusions, and authentication requirements
- Reviewed and standardized supported authentication methods
- Coordinated user MFA registration prior to policy enforcement
- Tested Conditional Access policies before organization-wide deployment
- Developed user-facing documentation and enrollment instructions
- Provided support for enrollment issues, MFA resets, and authentication failures
- Established procedures for users replacing devices or losing access to authentication methods

## Security Impact

The project strengthened identity security by moving beyond password-only authentication and implementing centralized, policy-based access controls through Microsoft Entra ID.

Conditional Access and Named Locations provided greater control over authentication requirements based on access conditions while maintaining reliable access to company resources.
