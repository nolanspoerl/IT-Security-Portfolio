
# iOS MDM Migration: Workspace ONE to Microsoft Intune

This project demonstrates the migration of **iOS device management from VMware Workspace ONE to Microsoft Intune**.

## Project Overview

Supported the migration of iOS devices from Workspace ONE to Intune using **EBF Onboarder** to simplify the enrollment and migration process.

The migration was designed as a primarily **user-driven process**, with users following a step-by-step guide to complete the migration on their devices.

## Technologies & Tools

* Microsoft Intune
* Apple iOS
* VMware Workspace ONE
* EBF Onboarder
* User enrollment documentation

## Key Tasks

* Planned and supported the migration from Workspace ONE to Intune
* Used EBF Onboarder to facilitate device migration
* Created user-facing migration instructions
* Communicated migration requirements and steps to users
* Provided support for enrollment and migration issues
* Validated successful device enrollment in Intune

## User Guide

A step-by-step **iOS migration user guide** is included with this project to demonstrate the user-driven migration process.

## Security & Privacy

This project has been recreated for portfolio purposes. No company-specific device information, user information, credentials, or proprietary configurations are included.
