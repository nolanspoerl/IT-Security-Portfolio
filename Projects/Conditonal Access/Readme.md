
# Conditional Access Policy Design Reference

This spreadsheet is a reference tool used to **design, model, and document Microsoft Entra ID Conditional Access policies** before and during implementation.

It provides a structured view of Conditional Access configurations, making it easier to review how policies interact and identify potential gaps, conflicts, or unintended access restrictions.

## Use Cases

The worksheet can be used to model and document:

- User, group, and administrative role assignments
- Application and user action targeting
- Device and platform conditions
- Named Locations and location-based controls
- User and sign-in risk policies
- Authentication and grant controls
- Session controls
- Policy exclusions and exceptions

## Implementation

I have used variations of this model throughout my career when planning and implementing Conditional Access environments. It provides a centralized reference for reviewing policy design, coordinating changes, and validating configurations before enforcement.

> **Note:** The version included in this portfolio has been sanitized and modified for demonstration purposes.
