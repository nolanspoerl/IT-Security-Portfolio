
# Microsoft Intune Deployment Packages

This directory contains Microsoft Intune deployment packages, scripts, and documentation created to demonstrate application deployment and endpoint management.

***ALL PROPRIETARY INSTALLERS AND .INTUNEWIN FILES HAVE BEEN REMOVED***

Examples are based on lab environments and sanitized recreations of solutions developed through professional experience.

## Technologies & Tools

- Microsoft Intune
- Microsoft Entra ID
- Windows 10/11
- PowerShell
- Win32 Application Deployment
- Microsoft Intune Management Extension (IME)
- MSI / EXE Installers

## Deployment Workflow

Typical deployments include:

1. Identify silent installation and uninstall parameters.
2. Create and test installation scripts.
3. Package applications for Microsoft Intune.
4. Configure requirements and detection rules.
5. Deploy to a test group and validate installation.
6. Troubleshoot deployment failures and endpoint logs.
7. Deploy to production groups after successful testing.
